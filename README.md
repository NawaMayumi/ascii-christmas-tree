# ASCII Christmas Tree

Instagramのリール「ASCII Christmas Tree」(https://www.instagram.com/reel/DfmBvgUNizn/) に着想を得た、文字だけで描かれたクリスマスツリーのWebページです。

- 上段: canvasで描く3D回転ツリー(枝の房構造・ガーランド・オーナメント・頂上の星・雪の地面・鉢と幹)
- 下段: ツリーを生成するnumpyスタイルのPythonコードが自動タイピングされるエディタ風表示

`index.html` を開くだけで動作します(外部依存はGoogle FontsのJetBrains Monoのみ)。
